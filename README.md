# 👑 老婆大人｜貓咪熱量計算器

輸入罐頭重量、每公克熱量、加了多少水、最後剩下多少，算出貓咪實際吃進去的罐頭熱量，並列出完整算式。

網址（開啟 GitHub Pages 之後）：https://pyhuanglaw.github.io/JILL-/

## 計算方式

罐頭和水拌勻後，剩下的部分也是同樣比例的罐頭＋水，所以：

1. 總重量 = 罐頭 + 水
2. 吃掉重量 = 總重量 − 剩下
3. 罐頭佔比 = 罐頭 ÷ 總重量
4. 吃掉罐頭 = 罐頭佔比 × 吃掉重量
5. 攝取熱量 = 吃掉罐頭 × 每公克熱量

每一步都四捨五入到小數點後兩位（罐頭佔比是百分比的小數點後兩位，例如 83.33%），下一步就用這個四捨五入後的數字往下算，所以畫面上的每一行算式都可以自己用計算機對得起來。

## 功能

- 手機上輸入時會跳出數字鍵盤（有小數點）
- 重量可輸入到小數點後兩位；自訂的每公克熱量可到小數點後三位（例如 0.966）
- 罐頭重量、加水、剩下都有「0」快速按鈕
- 「上一筆計算」會顯示真正的前一筆（重複按計算不會覆蓋）
- 輸入到一半重新整理頁面也不會不見；紀錄只存在自己手機的瀏覽器裡
- 「加入主畫面」後，圖示名稱是「老婆大人」
- 每次算好熱量，家裡五隻貓（白色金吉拉、橘色金吉拉、兩隻虎斑、美國短毛）會隨機跳一隻出來說「媽咪我愛你 ❤️」

## 開啟 GitHub Pages

Settings → Pages → Build and deployment → Source 選「Deploy from a branch」→ Branch 選 `main`、資料夾 `/ (root)` → Save。

## 自動測試

每次有新的修改推上 GitHub，GitHub Actions 會自動用 iPhone（Safari 引擎）和 Android（Chrome 引擎）兩種手機各跑一次 `tests/calculator.spec.js` 裡的測試，包括：數字鍵盤、小數點兩位限制、0 按鈕、截圖的例子 6.38 大卡、上一筆是否正確、重新整理後資料還在、錯誤提醒，以及隨機 500 組數字的算式檢查。結果在 repo 的 **Actions** 分頁可以看到。

自己電腦上跑：

```bash
npm ci
npx playwright install webkit chromium
npm test
```
