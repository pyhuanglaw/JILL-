# 🐱 貓咪熱量計算器

輸入罐頭重量、每公克熱量、加了多少水、最後剩下多少，算出貓咪實際吃進去的罐頭熱量，並列出完整算式。

網址（開啟 GitHub Pages 之後）：https://pyhuanglaw.github.io/JILL-/

## 計算方式

罐頭和水拌勻後，剩下的部分也是同樣比例的罐頭＋水，所以：

1. 總重量 = 罐頭 + 水
2. 吃掉重量 = 總重量 − 剩下
3. 吃掉罐頭 = (吃掉重量 ÷ 總重量) × 罐頭
4. 攝取熱量 = 吃掉罐頭 × 每公克熱量

每一步都四捨五入到小數點後兩位，所以畫面上的每一行算式都可以自己用計算機對得起來。

## 功能

- 手機上輸入時會跳出數字鍵盤（有小數點）
- 重量可輸入到小數點後兩位；自訂的每公克熱量可到小數點後三位（例如 0.966）
- 罐頭重量、加水、剩下都有「0」快速按鈕
- 「上一筆計算」會顯示真正的前一筆（重複按計算不會覆蓋）
- 輸入到一半重新整理頁面也不會不見；紀錄只存在自己手機的瀏覽器裡
